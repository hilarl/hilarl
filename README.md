## Hilal Agil

Research on **self-improving AI** and **sovereign compute** — systems that can be checked, and that
run on any hardware.

**[Tenzro](https://github.com/tenzro)** (2024) — the distributed computing network and
infrastructure.

**[Furcate](https://github.com/furcateai)** (2025) — the distributed intelligence system.

**[Furcate OS](https://github.com/furcateresearch)** (2026) — the operating system. One-step installation of
the entire stack, on any machine.

**[Living Worlds](https://livingworldslab.com)** (2026) — current focus. Simulated worlds built from baseline
data, where agents, species and models live and learn.

### Background

*[Decadence](https://open.spotify.com/album/2IhweFSLiYirosGe7WcRs7)* (2012), with
[Nothnegal](https://en.wikipedia.org/wiki/Nothnegal), is a concept album set in a future governed by
artificial intelligence. *[Singularity](https://open.spotify.com/track/1i4tTyQFVISc3sg1mnnql1)* is
about the self-improving AI at its centre, and the distributed intelligence it runs on.

*[Ectopia](https://github.com/hilarl/ectopia)* (2019) turned it into a blueprint, carrying the same
name for its computing layer. The systems have been built from it since, step by step.
